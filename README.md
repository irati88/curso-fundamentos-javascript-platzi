# Fundamentos de JavaScript – Platzi

Repositorio con los **ejercicios y prácticas** realizados durante el **Curso de Fundamentos de JavaScript** de **Platzi**, como parte de mi proceso de aprendizaje tras finalizar un **bootcamp de Programación Web Full Stack**.

Este proyecto tiene como objetivo **reforzar las bases de JavaScript** y mejorar la lógica de programación mediante ejemplos prácticos.

---

## Contenidos

- Estructuras de Control y Lógica  
- Funciones y This  
- Manipulación de Arrays  
- Programación Orientada a Objetos  
- Asincronía en JavaScript  

---

## Tecnologías

- JavaScript (ES6+)
- HTML5 / CSS3 (básico)
- Visual Studio Code
